# المرحلة السادسة — لوحات التحكم والتحليلات

## التركيب السريع

### 1. انسخ الملفات الجديدة

```
من: phase6-analytics/new-files/
إلى: مشروعك/

  analytics.html                    ← صفحة التحليلات الكاملة

من: phase6-analytics/new-files/assets/js/
إلى: مشروعك/assets/js/

  analytics-engine.js               ← محرك التحليلات (نمو، اتجاه، توقعات)

من: phase6-analytics/new-files/assets/js/pages/
إلى: مشروعك/assets/js/pages/

  analytics.js                      ← منطق صفحة التحليلات
```

### 2. استبدل الملفات المُحدَّثة

```
من: phase6-analytics/updated-files/assets/js/pages/
إلى: مشروعك/assets/js/pages/

  reports.js                        ← تقارير مع قسم تحليلات النمو
```

### 3. اختبار سريع

1. سجّل دخول كمدير → القائمة الجانبية تعرض «التحليلات»
2. افتح `analytics.html` → سترى:
   - 8 بطاقات KPI مع معدلات نمو (مقارنة بالفترة السابقة)
   - رسمان بيانيان للنمو (الإيرادات + الطلبات)
   - قمع التحويل (استفسارات → طلبات → مكتملة)
   - جدول ربحية الخدمات
   - جدول أداء الموظفين
   - معدل احتفاظ العملاء
   - توقعات شفافة (مع تنبيه واضح)
3. جرّب فلاتر زمنية مختلفة (7/30/90/365 يوم)
4. افتح `reports.html` → ستجد قسم «معدلات النمو» في الأعلى

## الميزات الجديدة

### 1. محرك التحليلات (analytics-engine.js)
دوال حسابية مشتركة للتحليلات:
- **computeGrowthRate()** — معدل النمو بين فترتين
- **linearRegression()** — انحدار خطي مع R² لقياس الجودة
- **forecastValues()** — توقعات شفافة مع مستوى ثقة
- **computeConversionFunnel()** — قمع التحويل
- **computeRetentionRate()** — معدل احتفاظ العملاء
- **computeServiceProfitability()** — ربحية كل خدمة
- **computeEmployeePerformance()** — أداء كل موظف
- **computeAnalyticsSummary()** — ملخص تحليلي شامل

### 2. صفحة التحليلات (analytics.html + analytics.js)
8 أقسام رئيسية:

| القسم | المحتوى |
|-------|---------|
| مؤشرات الأداء | 8 بطاقات مع معدلات نمو (مقارنة بالسابق) |
| رسوم النمو | الإيرادات الشهرية + الطلبات الشهرية |
| قمع التحويل | استفسارات → طلبات → مكتملة مع نسب |
| ربحية الخدمات | إيراد، تكاليف، تعويضات، ربح، هامش لكل خدمة |
| أداء الموظفين | مهام، إكمال، متوسط وقت، مستحقات |
| احتباز العملاء | عملاء عادوا، جدد، معدل الاحتفاظ |
| توزيع الحالات | رسم دائري لحالات الطلبات |
| التوقعات | توقع الإيراد والطلبات (مع تنبيه شفاف) |

### 3. التوقعات الشفافة
التوقعات مبنية على الانحدار الخطي للبيانات التاريخية:
- **الحد الأدنى للبيانات**: 3 نقاط (إلا، يظهر رسالة «بيانات غير كافية»)
- **مستوى الثقة**: عالي (R²>0.7)، متوسط (R²>0.4)، منخفض
- **اتجاه**: تزايد، تراجع، مستقر
- **تنبيه واضح**: «تقدير مبني على البيانات التاريخية — ليس نتيجة مضمونة»
- **شفافية كاملة**: يُعرض عدد الفترات المستخدمة + R² + الإشعار

### 4. تقارير محسّنة (reports.js)
- قسم جديد «معدلات النمو» في أعلى صفحة التقارير
- 6 معدلات نمو مع مؤشرات ↑↓
- قمع التحويل مدمج
- متوسط قيمة الطلب
- يستخدم analytics-engine.js للحسابات الموحّدة

## المبادئ المُطبَّقة

1. **التوقعات شفافة**: مبنية على بيانات تاريخية فعلية، مُعلَّمة كتقديرات
2. **عند نقص البيانات**: يُوضّح أن التوقع غير متاح بدل اختلاق أرقام
3. **مصدر موحّد**: analytics-engine.js يُستخدم في analytics وreports
4. **مقارنة دائمة**: كل KPI يُعرض مع معدل النمو عن الفترة السابقة
