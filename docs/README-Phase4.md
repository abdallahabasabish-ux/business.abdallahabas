# المرحلة الرابعة — الطلبات والمهام + الاستفسارات + لوحة الموظف

## التركيب السريع

### 1. انسخ الملفات الجديدة

```
من: phase4-tasks/new-files/
إلى: مشروعك/

  tasks.html                    ← صفحة إدارة المهام
  inquiries.html                ← صفحة إدارة الاستفسارات
  employee-dashboard.html       ← لوحة الموظف المنفصلة

من: phase4-tasks/new-files/assets/js/
إلى: مشروعك/assets/js/

  employee-dashboard.js         ← منطق لوحة الموظف
  pages/tasks.js                ← إدارة المهام
  pages/inquiries.js            ← إدارة الاستفسارات
```

### 2. استبدل الملفات المُحدَّثة

```
من: phase4-tasks/updated-files/assets/js/
إلى: مشروعك/assets/js/

  login.js                      ← توجيه ذكي (مدير/موظف/عميل)
  portal-orders.js              ← عرض المراحل المرئية للعميل

من: phase4-tasks/updated-files/assets/js/pages/
إلى: مشروعك/assets/js/pages/

  orders.js                     ← دورة حياة + تعيين متعدد + موافقات
```

### 3. تحديث القائمة الجانبية

القائمة الجانبية في sidebar.js (من المرحلة 3) تتضمن بالفعل روابط tasks.html وinquiries.html. لا حاجة لتعديل.

### 4. اختبار سريع

1. سجّل دخول كمدير → القائمة الجانبية تعرض «المهام» و«الاستفسارات»
2. افتح tasks.html → أنشئ مهمة، عيّن موظفًا، حدّد موعدًا وتعويضًا
3. افتح inquiries.html → أضف استفسارً، جرّب تحويله لطلب
4. سجّل دخول كموظف → يجب أن يُوجّه تلقائيًا لـ employee-dashboard.html
5. في لوحة الموظف: شاهد مهامك، حدّث التقدّم، سلّم للمراجعة
6. كمدير: في tasks.html، اضغط زر الاعتماد ✓ على مهمة قيد المراجعة
7. تحقق من ظهور المستحق في employeeLedger

## الميزات الجديدة

### 1. لوحة الموظف المنفصلة (employee-dashboard.html)
- **مهامي**: قائمة المهام المسندة للموظف فقط
- **إحصائيات شخصية**: إجمالي، قيد التنفيذ، مكتملة، متأخرة، مستحقات
- **مواعيد قادمة**: المهام المستحقة خلال 7 أيام مع تنبيهات
- **مستحقاتي**: من employeeLedger (أرباح، خصومات، مكافآت، مدفوعات)
- **تحديث التقدّم**: تحديد المراحل المكتملة، تسليم للمراجعة
- **تعليقات**: إضافة تعليقات على المهمة
- **لا يرى**: بيانات الشركة المالية، مهام موظفين آخرين، بيانات العملاء المالية

### 2. إدارة المهام الكاملة (tasks.html)
- **CRUD كامل**: إنشاء، عرض، تعديل، حذف
- **تعيين متعدد**: عدة موظفين على نفس المهمة (assignedEmployeeIds[])
- **8 حالات**: new, assigned, in_progress, under_review, completed, rejected, cancelled, overdue
- **أولوية**: منخفضة، متوسطة، عالية، عاجلة
- **تعويض**: مبلغ لكل مهمة يُسجَّل في employeeLedger عند الاعتماد
- **فلاتر**: بالحالة، بالموظف، بالبحث
- **اعتماد/رفض**: عند تسليم المهمة للمراجعة، المدير يعتمد أو يرفض

### 3. الاستفسارات والقيادات (inquiries.html)
- **CRUD كامل** مع 8 حالات (new, contacted, interested, quotation_sent, negotiation, converted, rejected, lost)
- **7 مصادر**: website, phone, email, social, referral, walk_in, other
- **تحويل لطلب**: زر يحوّل الاستفسار إلى طلب جديد ويحدّث الحالة
- **إحصائيات**: معدل التحويل، القيمة التقديرية، المفقود

### 4. تحديث الطلبات (orders.js)
- **دورة حياة كاملة**: inquiry → pending → approved → in_progress → under_review → completed
- **موافقة قبل العمل**: approvalStatus (pending/approved/rejected) + زر موافقة
- **تعيين متعدد**: عدة موظفين على نفس الطلب
- **مراحل مرئية للعميل**: كل مرحلة لها خيار customerVisible
- **حقول جديدة**: lifecycleStage, approvedAt, approvedBy, actualDeliveryDate

### 5. التوجيه الذكي (login.js)
بعد تسجيل الدخول:
- **مدير/محاسب** → dashboard.html
- **مشرف/موظف** → employee-dashboard.html
- **عميل** (له وثيقة customers) → portal-dashboard.html

### 6. بوابة العميل المحدّثة (portal-orders.js)
- عرض المراحل المرئية فقط (customerVisible == true)
- شارة حالة الموافقة (بانتظار/معتمد/مرفوض)
- شريط تقدّم إجمالي

## التكامل مع المراحل السابقة

| المرحلة | التكامل |
|---------|---------|
| الثانية (القواعد) | قواعد tasks وinquiries جاهزة — تُطبّق فورًا |
| الثالثة (الصلاحيات) | canViewTasks، canAssignTasks، canViewInquiries تتحكم بالوصول |
| الثالثة (بوابة العميل) | portal-orders يعرض المراحل المرئية |
